# 🍱 Food Ordering System

A robust, full-stack web application designed to digitalize restaurant operations, from administrative menu management to customer order fulfillment.

---

## 🚀 Key Features

### 👨‍💼 Administrative Suite
* **Secure Management Dashboard**: A centralized hub for overseeing all restaurant data.
* **Dynamic Menu Control**: Admins can add new dishes, set prices, and write descriptions.
* **Image Upload System**: Integrated file browsing to upload dish photos directly to the server.
* **Live Kitchen Orders**: A dedicated view for chefs to track incoming orders, customer names, and totals.
* **Order Status Tracking**: Update orders from 'Pending' to 'Ready' with a single click.

### 🛒 Customer Experience
* **Visual Menu**: A clean, card-based UI showcasing items like Biriyani and Burgers with live pricing.
* **Shopping Cart**: Seamlessly add items to the cart and calculate totals.
* **Streamlined Checkout**: Simple payment method selection (e.g., Cash on Delivery) and order confirmation.

---

## 🛠️ Technical Stack

* **Frontend**: HTML5, CSS3 (Responsive Design)
* **Backend**: PHP 8.x
* **Database**: MySQL
* **Server**: Apache (XAMPP Environment)
